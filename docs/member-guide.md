# Member Guide - Using Todos

A complete guide for community members on how to use the Todo feature effectively.

## 🎯 Quick Start

### Accessing Your Todos

1. **Go to your profile**
   - Click your avatar/name in navigation
   - Or visit: `yoursite.com/members/your-username/`

2. **Find the Todo tab**
   - Look in your profile navigation
   - Click "Todo" (or custom label set by admin)

3. **View your dashboard**
   - See all your tasks at a glance
   - Quick stats displayed at top

---

## ✏️ Creating Todos

### Your First Todo

**Step-by-step:**

1. **Click "Add New"**
   - Located in todo navigation
   - Or click "+ Add Todo" button

2. **Fill in Todo Details**

   **Title** (Required)
   ```
   Example: "Complete project proposal"
   Tip: Be specific and actionable
   ```

   **Summary/Description**
   ```
   Example: "Prepare detailed proposal including budget,
   timeline, and resource requirements for Q4 project"
   Tip: Add all relevant details for context
   ```

   **Due Date** (May be required by admin)
   ```
   Click calendar icon
   Select date
   Time is set to end of day automatically
   ```

   **Category** (Optional)
   ```
   Select from dropdown
   Or create new (if enabled)
   Helps organize your tasks
   ```

   **Priority** (Optional)
   ```
   High - Urgent, important tasks
   Medium - Regular tasks
   Low - Nice to have, when time permits
   ```

3. **Save Todo**
   - Click "Add Todo" or "Save" button
   - You'll see confirmation message
   - Todo appears in your list

### Quick Tips for Good Todos

**✓ DO:**
- Use action verbs (Complete, Review, Send, Create)
- Be specific ("Call John about project" not "Call someone")
- Set realistic due dates
- Add detailed descriptions
- Use categories consistently

**✗ DON'T:**
- Make titles too long
- Skip due dates for time-sensitive tasks
- Forget to add context in description
- Create duplicate todos

## 📋 Managing Your Todos

### Viewing Your Todos

**List View:**
- Shows all todos in one list
- Sorted by due date (incomplete first)
- Completed tasks at bottom
- Color coding by priority

**Information shown:**
- ✓ Title
- ✓ Due date
- ✓ Category
- ✓ Priority level
- ✓ Status (Complete/Incomplete)

### Editing a Todo

1. **Find the todo** in your list
2. **Click "Edit"** button/icon
3. **Make changes** to any field
4. **Save** changes
5. **Confirm** update successful

**You can edit:**
- Title and description
- Due date
- Category
- Priority
- Status

### Marking as Complete

**Method 1: Quick Complete**
- Click checkbox next to todo
- Instantly marked complete
- Moves to completed section

**Method 2: Via Edit**
- Edit the todo
- Change status to "Complete"
- Save changes

**What happens:**
- ✓ Todo marked with completion date
- ✓ Moved to completed list
- ✓ No more reminders sent
- ✓ Counts toward completion stats

### Deleting a Todo

1. **Click "Delete"** button/icon
2. **Confirm deletion** in popup
3. **Todo permanently removed**

**⚠️ Warning:** Deletion is permanent! Consider marking as complete instead to keep history.

## 📁 Working with Categories

### Using Categories

**Why use categories?**
- Organize tasks by type
- Filter lists quickly
- See tasks by project/area
- Better overview

**Default categories:**
- Uncategorized (fallback)
- Any admin-created categories

### Creating Categories (if enabled)

1. **Open todo form** (Add New or Edit)
2. **Look for category dropdown**
3. **Click "Add New Category"**
4. **Enter category name**
   ```
   Examples:
   - Work
   - Personal
   - Project ABC
   - Learning
   - Health
   ```
5. **Save and use**

### Best Practices

**Good category structure:**
```
✓ Work
✓ Personal
✓ Projects
✓ Learning
✓ Health
```

**Too many categories:**
```
✗ Work-Monday
✗ Work-Tuesday
✗ Personal-Morning
✗ Personal-Evening
(Use due dates instead!)
```

## 🔔 Notifications & Reminders

### Email Notifications

**How it works:**
1. Todo with due date of TODAY
2. System checks in morning
3. Email sent to you
4. Contains todo title and link

**Controlling emails:**

1. **Go to your profile settings**
   - Click profile
   - Settings or Edit Profile
   - Look for "Todo Email Notifications"

2. **Toggle ON/OFF**
   - ON: Receive reminder emails
   - OFF: No emails (but in-site notifications may still work)

3. **Save settings**

**Email not arriving?**
- Check spam folder
- Verify setting is ON
- Ensure email address is correct
- Contact site admin if issue persists

### BuddyPress Notifications

**How it works:**
- Due date arrives
- Notification appears in notification center
- Bell icon shows count
- Click to view todo

**Viewing notifications:**
1. Click bell icon in header
2. See list of notifications
3. Click notification
4. Opens todo directly

## 🎯 Productivity Tips

### Effective Todo Management

**Daily routine:**
1. **Morning:** Check todo list, plan day
2. **During day:** Check off completed tasks
3. **Evening:** Review progress, plan tomorrow

**Weekly routine:**
1. **Monday:** Set week's priorities
2. **Friday:** Review week, clean up list
3. **Ongoing:** Add tasks as they come up

### Using Priorities

**High Priority:**
- Urgent deadlines
- Important meetings
- Critical tasks
- Do these FIRST

**Medium Priority:**
- Regular work
- Standard deadlines
- Most tasks fit here
- Do after high priority

**Low Priority:**
- Nice to have
- When time permits
- Long-term goals
- Do if time allows

### Due Date Strategies

**Set realistic dates:**
- Don't overcommit
- Buffer time for delays
- Consider dependencies

**Use date patterns:**
- Weekly reviews: Every Friday
- Recurring tasks: Same day monthly
- Project phases: Milestone dates

**For tasks without dates:**
- Use categories instead
- Create "Someday/Maybe" category
- Review periodically

## 🤝 Group Todos

### Understanding Group Tasks

**What are group todos?**
- Tasks created by group admins/mods
- Assigned to group members
- Show in your personal todo list
- Marked with group name

### Working with Group Todos

**In your todo list:**
- Shows like personal todos
- Tagged with group name
- Can mark complete
- Cannot edit details (admin only)
- Cannot delete (admin only)

**Completing group tasks:**
1. Find task in your list
2. Do the work
3. Mark as complete
4. Progress tracked by group admin

**Notifications:**
- Receive notification when assigned
- Reminder on due date
- May get update if task changed

## 🆘 Common Questions

### "I don't see the Todo tab"

**Possible reasons:**
- Feature disabled by admin
- Your user role doesn't have access
- Need to refresh/clear cache
- BuddyPress not active

**Solution:** Contact site administrator

### "Can't create categories"

**Reason:** Admin has disabled user categories

**Solution:**
- Use existing categories
- Ask admin to create needed categories
- Focus on existing organization

### "Forgot to set due date"

**Solution:**
1. Edit the todo
2. Add due date
3. Save changes
4. Will get reminder on that date

### "Accidentally deleted todo"

**Unfortunately:** Deletions are permanent

**Prevention:**
- Mark complete instead of delete
- Keep as history
- Can always delete later if needed

### "Not receiving emails"

**Check:**
1. Email notification setting ON in profile
2. Email address correct
3. Check spam folder
4. Contact admin if still not working
