# What's new in 4.0.1

Version 4.0.1 fixes group task completion, adds language-pack translations and tightens accessibility.

## Group tasks

- Group members see the tasks assigned to them on the Todos tab and can complete them. See [Group to-dos](../features/group-todos).
- The tab count and stats match what each viewer sees.
- The assign picker lists the first 100 members A to Z. The `bptodo_assignee_picker_limit` filter changes the number.
- Group and notification features load only when the BuddyPress Groups or Notifications component is active.
- The unlinked Reports page and its table library are removed. The Overview sub-tab covers per-member progress.

## Accessibility and appearance

- Each checkbox is announced with its task title, and touch targets are 40px.
- Edit moves focus to the title field, and Delete moves focus to the next task.
- Toast messages are announced politely.
- Edit and Delete are fully visible, and dark mode is easier to read.

## Other

- Translations load from WordPress.org language packs.
- Due dates follow the site's timezone.
